# Numerics: Educational float32 vs Production

## Educational contract (this repo)

All ports under `reference/`, `c/`, `cpp/`, `rust/`, and `go/` implement **IEEE float32**
math with a shared stable softmax:

```text
m = max(x)
softmax(x)_i = exp(x_i - m) / sum_j exp(x_j - m)
```

Golden fixtures in `fixtures/goldens.json` are generated by the Python NumPy reference
(`scripts/generate_goldens.py`, seed `20260728`).

Tolerances used by `verify_all.sh` / language tests:

| Op class | atol | rtol |
|----------|------|------|
| Elementwise / norms / softmax AttnRes | 1e-5 | 1e-5 |
| Matmul-heavy (KDA, FFN, MoE, MLA) | 1e-4 | 1e-4 |

## Production differences (official stack)

| Path | Production behavior | Educational behavior |
|------|---------------------|----------------------|
| Activations / weights | Often **bf16**; MoE router in fp32 | float32 throughout |
| Quantization | MXFP4 weights / MXFP8 activations (QAT) | Unquantized float32 |
| KDA prefill | FlashKDA CUTLASS or FLA Triton `chunk_kda` | Naive recurrent float32 |
| FlashKDA sigmoid | `tanh.approx.f32` based sigmoid | `1/(1+exp(-x))` |
| FlashKDA L2Norm | Warp shuffle + FMA tree (`torch_ref`) | `x / sqrt(sum(x²)+eps)` |
| FlashKDA chunk inverse | fp16acc Newton series on `(I-L)` | Exact recurrence (no chunk inverse) |
| MLA | FlashAttention-2 kernels | Eager matmul + softmax |
| MoE top-k | `torch.topk(..., sorted=False)` | Deterministic lexsort top-k; indices sorted ascending |
| Softmax | Framework softmax | Explicit stable softmax above |

## Why not bit-identical GPU ports?

FlashKDA and FlashAttention fuse hundreds of lines of architecture-specific CUDA.
Reimplementing them in C/Rust/Go would not help *learning the model equations* and
would not match without copying the kernels. The FLA `naive_recurrent_kda` form is the
canonical readable definition used for cross-language parity.

## Deterministic top-k (educational)

For each token row with scores `s[e]`:

1. Rank experts by score descending; ties → smaller expert index first.
2. Take the first `top_k` experts.
3. Sort those indices ascending for a stable gather order across languages.
4. Weights are gathered from **sigmoid scores** (not bias-adjusted scores), then
   renormalized — matching `KimiMoEGate`.
